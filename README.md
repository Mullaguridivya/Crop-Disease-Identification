# Crop Disease Identification using ResNet50

## Project Overview
This project identifies crop diseases using leaf images with the help of Deep Learning and the ResNet50 model. The system classifies healthy and diseased crop leaves to support early disease detection in agriculture.Flask app using ResNet50 to detect anthracnose and sooty mold in crops.

## Features
- Leaf image classification
- Deep learning-based prediction
- ResNet50 transfer learning model
- High accuracy disease detection
- Image preprocessing and augmentation

## Technologies Used
- Python
- TensorFlow / Keras
- ResNet50
- OpenCV
- NumPy
- Matplotlib

## Dataset
Mango leaf disease image dataset containing healthy and diseased leaf categories(i.e., black soothy modl, anthracnose).

## Model Used
ResNet50 pre-trained CNN model with transfer learning.

## Performance
- Accuracy: 97.5%
- Precision: 98%
- Recall: 99%
- F1-Score: 99%

## Applications
- Smart agriculture
- Early crop disease detection
- Farmer assistance systems
